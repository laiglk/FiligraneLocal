# Sécurité

## Documents personnels

Ne joins jamais à une issue, une discussion ou une pull request un document réel contenant des données personnelles : pièce d’identité, RIB, justificatif de domicile, contrat ou document administratif.

Pour reproduire un problème, utilise exclusivement un fichier fictif ou anonymisé.

## Signaler une vulnérabilité

Utilise de préférence l’onglet **Security** du dépôt et l’option de signalement privé lorsqu’elle est disponible. N’expose pas publiquement une vulnérabilité avant sa correction.

Filigrane Local fonctionne localement et ne contient aucun code réseau. Un filigrane limite les possibilités de réutilisation d’une copie, mais ne constitue pas une protection cryptographique.
