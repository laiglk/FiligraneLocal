# Contribuer

Les corrections et améliorations sont bienvenues.

1. Crée un fork du dépôt.
2. Travaille dans une branche dédiée.
3. Vérifie la compilation sur macOS avec `bash build.command`.
4. Ouvre une pull request en décrivant le changement et la façon de le tester.

N’ajoute aucune dépendance réseau ou service tiers sans expliquer précisément son utilité et son impact sur la confidentialité.

Pour les tests, utilise uniquement des documents fictifs ou anonymisés. Ne publie jamais de document personnel dans le dépôt ou dans une issue.
